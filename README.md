## Repository Structure

Here’s a brief overview of the folders in this repository:

### 1. **Documentation**
   This folder contains essential project documentation, including:
   - Paper
   - Poster
   - Technical report
   - UML diagrams and related files

### 2. **java_services**
   This folder holds all files related to Java-based components of the project, including:
   - Repositories
   - Controllers
   - Services that work with Java

### 3. **python_services**
   This folder contains all files related to Python-based components, including:
   - Repositories
   - Controllers
   - Services that work with Python

### 4. **Project_venv**
   This folder contains the virtual environment created for the project. It ensures that all contributors use the same set of tools, preventing conflicts during development.

### 5. **Shared_data**
   This folder contains a JSON file that holds user information. The data is shared between the Java and Python services, and thus it is stored in a separate folder for easy access and consistency.
